# 3D Web & Video Design Skills

A collection of 3D, web and video design skills made mainly for **editing, improving and experimenting with existing work**.

These skills aren't really meant to just generate an entire website from scratch. They're much more useful when you already have something and want to **make it better, change the style, add 3D elements, improve animations or completely rework parts of it**.

## The two skills

There are two versions included:

### iWeb

**iWeb is the standard version.**

It's the easier and faster option for normal website editing and design work. It's good for improving an existing website, adding animations, working on interactions or making a design feel more polished.

### ZWeb

**ZWeb is the more advanced version.**

ZWeb goes further with 3D, video, animations and more complex design work. It's made for pushing an existing project much further and creating more detailed visual experiences.

Because it's more advanced, ZWeb usually needs **more reasoning and more video context** to get the best results. For more complex projects, giving it more time and reference material can make a big difference.

Basically:

**iWeb → standard, faster, easier**

**ZWeb → advanced, more detailed, more reasoning**

## What they're good at

* Editing and improving existing websites
* Creating and working with 3D web elements
* Improving animations and interactions
* Working on video designs and motion
* Reworking existing layouts and designs
* Making interfaces feel more polished and modern
* Adding depth, effects and interactive elements
* Creating more interesting visual experiences

The main idea is simple: **give the skill something to work with and then push the design further.**

## 3D Web

The 3D skills are mainly focused on taking an existing website or design and turning it into something more interesting.

That can mean adding:

* 3D objects
* Interactive scenes
* Camera movement
* Smooth transitions
* Depth and lighting
* Scroll-based animations
* Hover effects
* WebGL-style experiences
* More advanced interactions

They can also be used to completely redesign parts of a site when needed.

## Video Design

The video skills are focused more on **editing and improving existing video work** rather than simply generating random videos.

They're useful for things like:

* Motion design
* Transitions
* Visual effects
* Titles and typography
* Cinematic compositions
* Editing existing scenes
* Improving pacing and presentation
* Creating more interesting visual sequences

## Use an MP4 if you can

One small tip that can make a surprisingly big difference:

**Give the skill an MP4 file whenever possible.**

Both skills work especially well when they have an actual video to work with. An MP4 gives them useful visual and timing context and can also help with adding **sound effects and audio-driven interactions** to the website.

This can make animations, buttons, transitions and other interactions feel much more alive instead of just moving around silently.

So if you have a video that fits the project, **throw the MP4 in.**

It can make the final result noticeably better.

## Editing first

One of the main things these skills are designed around is **editing**.

Instead of always starting with a blank page, you can give them an existing website, video, animation or concept and work from there.

So if something already looks good but could be better, that's where these skills are most useful.

## Have fun with it

There aren't really strict rules for how to use them.

Try different things, break the design, rebuild parts of it, add 3D where it doesn't normally belong or see how far you can push the animations.

The goal is basically to make it **look good, feel good and be fun to work with.**

---

### Note

These skills are especially useful for **editing and experimenting with existing projects**. They can still help with creating new things, but that's not really their main purpose.

If you want the more advanced experience, use **ZWeb**.

If you just want a solid standard workflow, **iWeb** is the one to use.
